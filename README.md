Chappie is an experiment in building agents that don’t reset every time you talk to them.

A couple days ago I shared this project and it got a lot more attention than I expected. A lot of people asked how it actually works, so I put the underlying system into a framework/blueprint you can explore here.

The core idea is simple:

Instead of treating an agent as a stateless input → output system, give it a continuous internal state that updates over time and influences behavior.

This repo is not a finished product. It’s a working design you can build on, break, or adapt into your own system.

If you end up using any part of it, share what you find. The goal is to figure this out together through real implementations, not just theory.
